# 节点进度、图片查看器与结果排序验收

## 实现

- 删除页面标语“让书架上的每一本书，都被看见。”、导入区“也可直接将图片拖入窗口”，以及结果区截图中的整块空白提示。
- 五个圆形进度节点：图片准备、书脊检测、矫正增强、文字识别、结果整理。底线为空心描边，完成节点为强调色圆底与白色勾号，填充线到最后完成节点；当前节点呼吸，完成后保留。
- 节点读取真实准备和 Python 命令启动事件；后续阶段启动代表前一段 subprocess 已成功返回，全部结果加载后才显示全部完成。取消保留已完成节点并显示暂停，失败显示红叉。
- 图片查看器支持滚轮围绕鼠标位置缩放、按住中键无边界平移、释放中键停止；失去指针捕获、切换图片、窗口卸载时结束拖动。
- 全屏按钮或双击打开当前原图 / 检测图。全屏有退出与缩放控件，Esc / 退出按钮 / 双击返回主界面。
- 排序仅有顺序与置信度两个选择。当前选择重复点击反向，切换选择保留各自方向。顺序按数字序号、置信度按未舍入 double 排列；同分按序号稳定排列。复制全部沿用显示顺序。
