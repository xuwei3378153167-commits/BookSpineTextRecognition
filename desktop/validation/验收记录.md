# 桌面应用改版验收

日期：2026-10-18。程序：WinUI 3 / .NET 8，自包含 x64 发布。

## 已交付

- 米白背景、`#DA7756` 强调色、中文界面；紧凑品牌区、图片预览和结果工作区。
- 高级设备参数弹出面板；正常 / 忙碌 / 完成 / 取消 / 失败状态。
- 原图与检测图切换，25%～800% 预览缩放及适应窗口。
- 可选中文字、每条独立复制按钮、复制全部 TSV。
- 原创书脊与扫描框图标，SVG / 透明 PNG / 多尺寸 ICO；程序文件、窗口、任务栏、现有快捷方式集成。
- 真实 Python 子进程阶段反馈。Windows Job Object 管理推理进程及其子进程，避免取消时产生孤立 OCR 进程。
